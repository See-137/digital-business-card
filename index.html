Agent Memory Layer

An agent that learns from every conversation, and forgets what it should.

  • Obsidian
  • Honcho
  • MCP
  • Node.js

What it does

  • An Obsidian vault holds durable knowledge, versioned in git
  • Honcho keeps a learned model of the operator, refreshed by a nightly pass that reviews the day's conversations and keeps only what lasts
  • Every write leaves an auditable export in the vault; secrets and identifiers are excluded by rule
  • Recalled memory shapes how the agent works, but can never authorise an action
